# 青空文庫のZIPを作品として表示する

青空文庫の「テキストファイル（ルビあり）」のZIPを、解凍せず作品フォルダーへ置けます。生成時にZIP内のテキストを読み込み、既存のMarkdown作品と同じ一覧・作品ページへ追加します。

## 配置

```text
novels/
  吾輩は猫である/
    789_ruby_5639.zip
    cover.png          # 任意：作品の表紙
    novel.json         # 任意：紹介文・ジャンルなど
```

**1フォルダー＝1作品**です。別の作品のZIPは別の作品フォルダーに入れてください。ファイル名は変更しなくて構いません。ZIPだけでも作品名と著者名をテキスト冒頭から取得し、ジャンル「青空文庫」、状態「完結済」で表示します。これは取り込み時の初期値なので、未完の作品などは `novel.json` の `status` を変更してください。

## ローカルで確認

初回または依存ライブラリー更新後は `npm ci` を実行します。

```bash
npm run build:site
npm run dev
```

ブラウザーで `http://localhost:5173/` を開き、作品名で検索します。プレビューがすでに起動中なら、生成後に再読み込みすれば反映されます。

## GitHub Pagesへ公開

ZIPと必要な画像・作品情報をcommitして `main` へpushしてください。GitHub Actionsが `docs/` のHTMLと一覧JSONを生成し、GitHub Pagesへ公開します。ZIPの差し替えも更新対象です。

初回のActions・Pages設定は [GitHub Actionsの設定手順](github-actions.md) を参照してください。

## 表示を調整する

例えば作品フォルダーの `novel.json` に次を書きます。

```json
{
  "title": "吾輩は猫である",
  "author": "夏目漱石",
  "genre": "日本文学",
  "description": "猫の視点から人間の暮らしを描く作品。",
  "status": "完結済",
  "priority": 50
}
```

指定した値を優先します。表紙は同じフォルダーの `cover.png` を自動検出します。非公開にするときは `draft: true` を指定します。

## 対応範囲

- Shift_JISとUTF-8のテキスト。改行はCRLF・LFに対応。
- `｜親文字《よみ》` と `漢字《よみ》` のルビ。本文の「ふりがな」で表示・非表示を切り替えます。原文のルビにはFurifontの読み込みは不要です。
- 音声はルビがある箇所の読みを使い、親文字と読みを二重に読みません。
- 基本的な見出し・改ページ。その他の注記は小さい説明文として残します。
- Unicode番号が書かれた外字の一部。それ以外の外字注記は説明を残し、外字画像・複雑な組版の再現は行いません。
- 底本・入力者・校正者などの情報は、本文末尾の「作品情報・底本・入力者など」に残します。本文の読み上げ対象には含めません。
- ZIP内の作品テキスト1ファイルを1話として表示します。テキスト内部の章を自動で別の話へ分割はしません。複数テキストがある場合はファイル名の自然順で並べます。
- READMEやライセンスのテキスト、隠しファイルは除外します。ZIP内の画像は取り込みません。挿絵や表紙をZIPから自動表示する機能はありません。
- 同じフォルダーにMarkdownも置けます。ZIPとMarkdownをファイルパス順に並べ、あとがきなどを追加できます。ZIPとMarkdownを混在させる場合、作品名・著者名は `novel.json` で指定することを勧めます。
- 取り込むテキストはZIPごとの解凍後合計64MiBまで。ZIPをディスクへ展開せず、メモリー内で読み込みます。

XHTML・PDFなどのZIPは対象外です。テキストを含まないZIPや壊れたZIPは、ファイル名を示して生成を止めます。

## 出典と利用案内

このツールは青空文庫の公式サービスではなく、テキストを閲覧用HTMLへ変換します。公開に利用する作品は、青空文庫の図書カードと [収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html) に従って選んでください。元ファイルの作品情報・底本・入力者等は生成ページに保持します。

- [青空文庫：ダウンロードと解凍](https://www.aozora.gr.jp/guide/download.html)
- [青空文庫：注記一覧](https://www.aozora.gr.jp/annotation/)

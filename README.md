# MdYomuKiku

Markdownで書いた小説から、読む・聴くことのできる静的サイトを生成するCLIです。普段はVS Codeなどで執筆し、コマンドで公開用HTMLを作ります。トップページと作品ごとのHTMLを生成します。

## 使い方

Node.js 22以上が必要です。

```bash
npm ci
npm run demo
```

プレビューサーバーは次のコマンドで起動できます。起動時にサンプルを再生成し、`docs/` をルートとして配信します。

```bash
npm run dev
```

`http://localhost:5173/` を開いてください。ポートは `PORT` 環境変数で変更できます。原稿変更後は別のターミナルで `npm run demo` を実行し、ブラウザーを再読み込みしてください。

`docs/index.html` をブラウザーで直接開いても、50作品・100話（本文合計約2万字）のオリジナル短編サンプルを読めます。作者名・作品・紹介文はサンプル用の創作です。公開するときは `docs` の内容を静的ホスティングへ配置します。このツール自体にアップロード機能はありません。

自分の作品を生成する場合：

```bash
npm run build -- ./novels ./docs
```

入力と出力は別のフォルダーにしてください。出力先には生成ファイルの管理用JSONも作られます。次回生成時に、削除・非公開にした作品の以前の生成HTMLを消すために使います。公開サーバーへの反映時も削除を同期してください。

## 原稿の構成

```text
novels/
  星を運ぶ郵便屋/
    novel.json
    01-夜の配達.md
    02-宛先のない星.md
    cover.png
```

1フォルダーが1作品です。各作品内のMarkdownをサブフォルダーも含めてファイルパスの自然順（2→10）で並べ、1ファイルを1話にします。章分けには `01-第一章/01.md` などの名前を使えます。公開しないメモは作品フォルダーの外に置いてください。ドットから始まるファイル・フォルダーは除外します。入力直下にMarkdownを置いた場合は、その直下のファイルを1作品として扱います。

各話の最初の `# 見出し` が話タイトルです。なければファイル名を使います。見出し・強調・リスト・引用・表・コード・リンク・画像などのMarkdownに対応します。生のHTMLは実行せず文字として表示します。

`novel.json` は省略可能です。

```json
{
  "title": "星を運ぶ郵便屋",
  "author": "水瀬 しおり",
  "genre": "ファンタジー",
  "description": "宛先のない手紙を、夜空の向こうへ。",
  "tags": ["星空", "旅"],
  "status": "完結済",
  "priority": 100,
  "updated": "2026-10-22",
  "cover": "cover.png",
  "draft": false
}
```

- `priority`：大きいほどおすすめ順で上に表示。正の値で「おすすめ」を表示。
- `updated`：更新日。省略時はMarkdownの最終更新日。
- `draft: true`：その作品を公開対象から除外。
- `cover`：作品フォルダーからの相対パス。省略すると `cover.png` を自動検出。画像がなければ文字入りの仮表紙を表示。表紙は1024×1536px（縦横比2:3）のPNGを推奨。

本文の画像は `![説明](images/scene.png)` と書きます。各Markdownからの相対パスで指定し、作品フォルダー内のPNG・JPEG・GIF・WebP・AVIFを使用できます。画像はBase64で埋め込みます。リモート画像や作品フォルダー外のファイルは受け付けません。

## フォント

初期値は **system** です。

```bash
npm run build -- ./novels ./docs --font system
npm run build -- ./novels ./docs --font embed
npm run build -- ./novels ./docs --font external
```

| 値 | 動作 |
| --- | --- |
| `system` | 端末の標準フォント。Furifontは出力しない。初期値 |
| `embed` | Furifontを各HTMLへBase64で埋め込む。各ページ約8.7MB増加 |
| `external` | `assets/FurifontSans-Regular.woff2` を全HTMLで共有。HTMLとassetsを一緒に公開 |

Furifont Sans Regular v0.6.2を収録しています。ふりがなはフォントの合字で描かれ、文脈や固有名詞で読みが誤る場合があります。Furifont使用時は本文でふりがなを無効にし、端末フォントに切り替えられます。利用条件と出典は [assets/fonts](assets/fonts/README.md) と生成HTML内に収録しています。

## 閲覧機能

- トップ：作品一覧、タイトル・作者・紹介文・タグ検索、ジャンル絞り込み、おすすめ順・更新順・名前順。
- 作品：紹介、表紙、目次、前後の話への移動、文字サイズ、昼夜の配色。
- 読書再開：ブラウザーのlocalStorageへ最後に開いた話を保存。同じブラウザー・同じ公開先で利用できます。話の途中のスクロール位置は保存しません。`file://` での保存可否はブラウザーに依存します。
- 音声：Web Speech APIを使った本文読み上げ、一時停止・再開・停止、速度と声の選択、読んでいる段落の強調。各話を最後まで読んだら停止します。

音声は端末やブラウザーの機能を使用し、音声データ自体はHTMLに含めません。利用できる声・日本語への対応・通信の必要性は端末によって異なります。フォントのふりがなと読み上げエンジンの読みは別です。

本文JSONとJavaScriptはBase64、CSSはインラインで保存します。`system` / `embed` なら各作品のHTML単体で本文を閲覧できます。作品一覧との相互リンクを使う場合は `index.html` と作品HTMLを同じフォルダーに置いてください。Base64は暗号化ではありません。出力された本文は閲覧者が取り出せます。

本文は作品ページにだけ含め、トップには紹介情報だけを入れます。非常に大きな作品はブラウザーのメモリーと読み込み時間を使います。ブラウザー内検索は作品情報が対象で、本文の横断検索は行いません。

現在の実装対象は小説サイトです。ブログ・商品紹介・管理画面・注文・決済は未実装です。

## 開発時の確認

```bash
npm test
npm run demo
```

自動テストはHTML生成、画像埋め込み、フォント3方式、検索・ジャンル、目次・読書再開、原稿の検証を対象にします。実端末のフォント描画や音声の品質はブラウザーで確認してください。

## GitHub Pages

生成した `docs/` をリポジトリへ含め、GitHubの Settings → Pages → Deploy from a branch で、公開するブランチと `/docs` を選択します。`docs/.nojekyll` も自動生成します。執筆後は再生成し、更新した原稿と `docs/` を反映してください。

表紙用プロンプトは [guides/cover-prompts.md](guides/cover-prompts.md)、機械可読版は [guides/cover-prompts.json](guides/cover-prompts.json) にあります。
